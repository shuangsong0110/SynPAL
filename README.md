# SynPAL
Synthetic Phenotype-Assisted Likelihood for genome-wide association studies of partially observed phenotypes.

Many high-value phenotypes in biobanks, such as multi-omics and imaging traits, are measured in only a subset of participants. SynPAL combines the **observed** phenotype (labeled samples) with a **synthetic** phenotype generated by machine learning or generative AI for *all* samples: it calibrates and augments the synthetic phenotype and performs likelihood-based inference for continuous, binary and count phenotypes. SynPAL is robust to misspecification of the generative model and to covariate shift between labeled and unlabeled samples, and guarantees efficiency gains over the analysis of labeled samples alone.

## :package: Installation

```r
install.packages("devtools")
devtools::install_github("shuangsong0110/SynPAL")
```

**Operating system.** Linux. Tested on Rocky Linux 8.10 with R 4.3.0.

**Software dependencies.** R (>= 3.6) and the R packages below, which are installed automatically. The demo was run with the versions listed.

## :dna: Step 1: Prepare the input files

SynPAL reads three inputs; samples are matched across them by `IID`.

| Input | Format |
|-------|--------|
| Genotypes | PLINK 1 binary files `<prefix>.bed`, `<prefix>.bim` and `<prefix>.fam`. |
| Phenotype file | A headed, whitespace-delimited table with the columns `IID`, `pheno` and `s_pheno`. |
| Covariate file | A headed, whitespace-delimited table with the column `IID` followed by the covariates (for example age, sex and genetic principal components). |

Phenotype file:

| IID | pheno | s_pheno |
|-----|-------|---------|
| sample_1 | 1.24 | 0.68 |
| sample_2 | -0.53 | -0.11 |
| sample_3 | NA | 0.42 |
| ... | ... | ... |

*(The rows above are synthetic and for illustration only.)*

- `pheno`: the **observed** phenotype; `NA` for the samples in which it was not measured.
- `s_pheno`: the **synthetic** phenotype, provided for **all** samples. It can be generated with any machine-learning or generative-AI model from the predictors available for the full cohort.

Three types of phenotype are supported:

| Phenotype | `model` | `pheno` | `s_pheno` |
|-----------|---------|---------|-----------|
| Continuous | `"linear"` | the measured value | the predicted value |
| Binary | `"logistic"` | 0 or 1 | the predicted probability, between 0 and 1 |
| Count | `"poisson"` | a non-negative integer | the predicted count, non-negative |


## :rocket: Step 2: Run SynPAL

```r
library(SynPAL)
res <- synpal_gwas(bfile = "mydata",              # mydata.bed, mydata.bim, mydata.fam
                   pheno = "mytrait_pheno.txt",
                   covar = "covar.txt",
                   model = "linear",              # "linear", "logistic" or "poisson"
                   out   = "mytrait_synpal.txt")
```

- `screen_p` (default `5e-4`): SynPAL is run on the variants whose P-value in the labeled samples is at most `screen_p`; `screen_p = 1` runs it on every variant.
- `ncores` (default `1`): the number of cores.

#### Output: one row per variant, returned as a data frame and written to `out`

| Column | Description |
|--------|-------------|
| `CHR`, `SNP`, `BP` | Chromosome, variant ID and position, from the `.bim` file. |
| `A1` | The effect allele: the first allele of the `.bim` file. |
| `BETA` | SynPAL estimate of the effect per copy of `A1` (log odds ratio for `"logistic"`, log rate ratio for `"poisson"`). |
| `SE` | Standard error of `BETA`. |
| `P` | SynPAL P-value. |
| `P_labeled` | P-value from the labeled samples alone. |

`BETA`, `SE` and `P` are given for the variants that pass `screen_p`.

A single variant can be tested from vectors in R with `synpal_test(y, s, g, x, model)`, where `y` is the observed phenotype (`NA` if unobserved), `s` the synthetic phenotype, `g` the genotype and `x` the covariate matrix.


## :test_tube: Demo

The package ships a small simulated dataset, generated by [`data-raw/simulate_demo_data.R`](data-raw/simulate_demo_data.R) with a fixed seed (all sample IDs, genotypes, covariates and phenotypes are simulated):

- 5,000 samples and 500 SNPs, five of which are causal;
- four covariates (`age`, `sex`, `pc1`, `pc2`);
- a continuous, a binary and a count phenotype, each observed in 30% of the samples, with a synthetic phenotype for all samples.

**Run** (in R, after installation):
```r
library(SynPAL)
d <- system.file("extdata", package = "SynPAL")

res <- synpal_gwas(file.path(d, "demo"), file.path(d, "demo_pheno_continuous.txt"),
                   file.path(d, "demo_covar.txt"), model = "linear")
head(res[order(res$P), ])
```
The binary and count phenotypes are run in the same way, with `demo_pheno_binary.txt` and `model = "logistic"`, or `demo_pheno_count.txt` and `model = "poisson"`.

**Expected output.** For the continuous phenotype:

**Run time.** Each of the three runs takes less than 1 second on one core (Intel Xeon Platinum 8480CL, single thread; peak memory under 0.5 GB). Testing all 500 SNPs (`screen_p = 1`) takes about 3 seconds.
